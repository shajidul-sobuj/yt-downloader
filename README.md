# YouTube Downloader

একটি সম্পূর্ণ YouTube ভিডিও ও প্লেলিস্ট ডাউনলোডার ওয়েব অ্যাপ্লিকেশন যা উচ্চ মানের অডিওসহ ভিডিও ডাউনলোড করতে পারে।

## বৈশিষ্ট্য

✅ একক ভিডিও ডাউনলোড  
✅ সম্পূর্ণ প্লেলিস্ট ডাউনলোড  
✅ বিভিন্ন মান অপশন (1080p, 720p, 480p, 360p, 240p)  
✅ স্বয়ংক্রিয় সেরা মান নির্বাচন  
✅ রিয়েল-টাইম ডাউনলোড প্রগতি  
✅ সুন্দর এবং প্রতিক্রিয়াশীল ইউআই  

## প্রয়োজনীয়তা

- Python 3.8+
- pip

## ইনস্টলেশন

```bash
# প্রজেক্ট ডিরেক্টরিতে যান
cd YouTube-Downloader

# Dependencies ইনস্টল করুন
pip install -r requirements.txt
```

## চালু করা

```bash
python main.py
```

তারপর আপনার ব্রাউজারে খুলুন:
```
http://localhost:8000
```

## ব্যবহার

1. YouTube URL পেস্ট করুন (ভিডিও বা প্লেলিস্ট)
2. "Get Info" বোতাম ক্লিক করুন
3. পছন্দের মান নির্বাচন করুন
4. "Download" বোতাম ক্লিক করুন
5. ডাউনলোড সম্পন্ন হওয়ার জন্য অপেক্ষা করুন

## ডাউনলোড করা ফাইলগুলি

ডাউনলোড করা ভিডিওগুলি `downloads/` ফোল্ডারে সংরক্ষিত হয়।

## API Endpoints

- `GET /api/info?url=...` - ভিডিও/প্লেলিস্টের তথ্য পান
- `POST /api/download?url=...&format_id=...&is_playlist=...` - ডাউনলোড শুরু করুন
- `GET /api/progress` - ডাউনলোড প্রগতি পান
- `GET /api/result` - ডাউনলোড ফলাফল পান

## প্রযুক্তি স্ট্যাক

- **Backend**: FastAPI
- **Video Downloader**: yt-dlp
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
