📊 প্রযুক্তি স্ট্যাক:

  Backend:   FastAPI + Python
  Frontend:  HTML5 + CSS3 + JavaScript
  Download:  yt-dlp (YouTube ডাউনলোডার লাইব্রেরি)
  Server:    Uvicorn (ASGI)

🎓 কীভাবে কাজ করে:

  1. ব্যবহারকারী YouTube URL পেস্ট করে
  2. "Get Info" ক্লিক করলে ভিডিও তথ্য আসে
  3. কোয়ালিটি নির্বাচন করে "Download" ক্লিক করে
  4. Backend (yt-dlp) ভিডিও ডাউনলোড করে
  5. Frontend রিয়েল-টাইম প্রগতি দেখায়
  6. ডাউনলোড সম্পন্ন হলে downloads/ ফোল্ডারে সংরক্ষিত হয়
